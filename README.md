# Data Engineering Projects

ETL pipelines and data analysis projects using Python, PostgreSQL and SQL.

## Projects

### 1. Titanic ETL Pipeline
- Loaded Titanic dataset using pandas
- Cleaned missing values (Age, Cabin, Embarked)
- Stored clean data in PostgreSQL
- Analyzed survival rates by gender and class using SQL

### 2. Netflix ETL Pipeline
- Loaded Netflix dataset using pandas
- Cleaned missing values (ratinglevel, user_rating_score)
- Stored clean data in PostgreSQL
- Queried top-rated titles using SQL

## Tools Used
- Python, pandas, SQLAlchemy
- PostgreSQL, pgAdmin 4
- GitHub
